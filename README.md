# CRM-Sales-Analytics-Dashboard
![Salary Dashboard GIF](https://github.com/swatipand/CRM-Sales-Analytics-Dashboard/blob/main/Sales_Dashboard_1.gif)

## Introduction

Interactive CRM Sales Analytics Dashboard built using Power BI, PostgreSQL, SQL, and DAX to analyze revenue, customer performance, product sales, and key business KPIs.


## 📌 Project Overview

This project is an Executive Sales Analytics Dashboard developed using Power BI and PostgreSQL. The dashboard helps analyze sales performance, customer behavior, product performance, and profitability through interactive visualizations and KPIs.

---

## 🎯 Business Objective

The objective of this dashboard is to help management monitor key business metrics and make data-driven decisions by providing:

- Revenue Analysis
- Margin Analysis
- Customer Performance
- Product Performance
- Monthly Sales Trends
- Interactive Filtering

## 📊 Dashboard Features

- Total Revenue

- Margin %

### Interactive Filters

- Customer
- Product
- State
- Month

### Visualizations

- Monthly Revenue Change
- Top 10 Customers
- Top 10 Products
- Monthly Margin %

---

## 🗂 Data Model

The dashboard follows a star-schema style data model using PostgreSQL.

Main Tables:

- Sales
- Customers
- Calendar

Additional SQL Views:

- Customer Retention
- Product Performance
- Monthly Sales
- Customer Health
- Customer 360
